# 🛒 React E-Commerce & Admin Suite

A production-ready e-commerce web application built with React. It features a complete public storefront, seamless shopping cart management, a dynamic blog platform, Google AdSense integration, and a full-featured **Admin Dashboard** for managing products, orders, and store content.

---

## ✨ Key Features

* **Dynamic Storefront:** Browse through categorized products, detailed views, and custom filters.
* **Interactive Cart & Checkout:** Real-time cart management and seamless checkout flow[cite: 1].
* **Integrated Blog System:** Dedicated content management and article-reading framework[cite: 1].
* **Comprehensive Admin Dashboard:** 
  * Product inventory control via interactive modals[cite: 1].
  * Order tracking and management interface[cite: 1].
  * CSV data import/export tools and store settings[cite: 1].
* **Monetization & Utilities:** Built-in Google AdSense support (`ads.txt`) and serverless image upload capabilities[cite: 1].
* **Legal & Support Pages:** Pre-configured Privacy Policy, Terms & Conditions, Shipping/Return policies, and FAQ pages[cite: 1].

---

## 🛠️ Tech Stack

* **Frontend:** React.js, React Router
* **Backend / Database:** Firebase Integration[cite: 1]
* **Serverless Functions:** Vercel API routes (`/api/upload-image.js`)[cite: 1]
* **State Management:** React Context API (`CartContext`, `BlogContext`, `SearchContext`, `ToastContext`)[cite: 1]
