# React E-Commerce & Admin Suite

A production-ready e-commerce web application built with React. It features a complete public storefront, seamless shopping cart management, a dynamic blog platform, Google AdSense integration, and a full-featured **Admin Dashboard** for managing products, orders, and store content.

---

## Key Features

* **Dynamic Storefront:** Browse through categorized products, detailed views, and custom filters.
* **Interactive Cart & Checkout:** Real-time cart management and seamless checkout flow.
* **Integrated Blog System:** Dedicated content management and article-reading framework
* **Comprehensive Admin Dashboard:** 
  * Product inventory control via interactive modals.
  * Order tracking and management interface.
  * CSV data import/export tools and store settings.
* **Monetization & Utilities:** Built-in Google AdSense support (`ads.txt`) and serverless image upload capabilities.
* **Legal & Support Pages:** Pre-configured Privacy Policy, Terms & Conditions, Shipping/Return policies, and FAQ pages.

---

## Tech Stack

* **Frontend:** React.js, React Router
* **Backend / Database:** Firebase Integration
* **Serverless Functions:** Vercel API routes (`/api/upload-image.js`)
* **State Management:** React Context API (`CartContext`, `BlogContext`, `SearchContext`, `ToastContext`)

## Getting Started

Follow these steps to set up and run the project locally on your machine:

### Prerequisites
* Make sure **Node.js** and **npm** are installed on your system.

### Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone "https://github.com/sameerirfangaba/Ecommerce_Website_React.git"

2. **Navigate to the project directory:**
   ```bash
   cd Ecommerce_Website_React
   
3. **Install dependencies:**
   ```bash
   npm install
   
4. **Environment Configuration::**
   * Set up your **.env** file with the required Firebase configuration keys.

5. **Run the development server:**
   ```bash
   npm start
